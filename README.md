# Local File Share

Небольшое веб-приложение для передачи файлов между компьютером и телефоном в одной локальной сети. После запуска приложение выводит адрес, QR-код и временный PIN-код. Пользователь открывает страницу в браузере, вводит PIN и может загружать, скачивать и удалять файлы.

Проект создан в учебных целях для знакомства с FastAPI, HTTP, сессиями, обработкой файлов и базовыми вопросами информационной безопасности.

## Возможности

- Вход по временному шестизначному PIN-коду.
- Создание сессии с ограниченным временем действия.
- Загрузка файлов через выбор файлов или перетаскивание.
- Скачивание и удаление загруженных файлов.
- Отображение QR-кода со ссылкой на приложение.
- Ограничение размера одного файла (100 MiB) и общего количества файлов (50).
- Потоковая запись загружаемого файла небольшими блоками.

## Установка и запуск

Требуется Python 3.10 или новее.

### 1. Склонировать репозиторий

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

### 2. Создать виртуальное окружение

Windows:

```powershell
py -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустить приложение

Только на этом компьютере:

```bash
python app.py
```

Чтобы разрешить подключение с других устройств в той же локальной сети:

```bash
python app.py --lan
```

После запуска в терминале появятся адрес приложения, PIN-код и QR-код. Открой адрес на телефоне или другом устройстве и введи PIN-код.

## Настройки

Основные параметры находятся в `config.py`:

| Параметр | Значение по умолчанию | Назначение |
|---|---:|---|
| `MAX_FILE_SIZE` | 100 MiB | Максимальный размер одного файла |
| `MAX_FILES_TOTAL` | 50 | Максимальное общее количество файлов |
| `PIN_TTL_SECONDS` | 300 секунд | Срок действия PIN-кода |
| `SESSION_TTL_SECONDS` | 3600 секунд | Срок действия сессии |
| `MAX_PIN_ATTEMPTS` | 5 | Число неверных попыток PIN с одного IP |
| `PORT` | 8000 | Порт веб-сервера |

## Меры безопасности, реализованные в проекте

- PIN генерируется модулем `secrets`.
- Сравнение PIN выполняется через `secrets.compare_digest`.
- Токены сессий создаются криптографически стойким генератором.
- Сессионная cookie имеет флаги `HttpOnly` и `SameSite=Strict`.
- Идентификаторы файлов генерируются как UUID и проверяются перед обращением к файловой системе.
- Имя загружаемого файла очищается от пути и небезопасных символов.
- Размер загрузки проверяется во время потоковой записи, а не после чтения всего файла в память.
- По умолчанию сервер слушает только `127.0.0.1`. Для доступа из локальной сети требуется явный параметр `--lan`.

## Ограничения и замечания

Это учебный локальный проект, а не готовое публичное файловое хранилище.

- В режиме `--lan` приложение использует HTTP без TLS. Не используйте его в недоверенных сетях и не открывайте порт в интернет.
- `COOKIE_SECURE` по умолчанию выключен, поскольку локальный режим работает по HTTP. При настройке HTTPS следует включить этот параметр.
- PIN и сессии хранятся в памяти процесса. После перезапуска сервера все активные сессии сбрасываются.
- Ограничение числа файлов общее для приложения, а не отдельное для каждого пользователя.
- Данные хранятся без шифрования на диске.
- Для промышленного использования потребуются HTTPS, постоянное хранилище с разграничением доступа, более строгие лимиты запросов, журналирование и дополнительные проверки.
